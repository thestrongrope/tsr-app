### Quirks copied (each is in a Hurl file on both sides)
- **Active teachers:** teachers are filtered by THEIR OWN gender (`users.gender = :gender`, compared as the text "1"/"2": a gents-class teacher whose member gender is ladies is in neither list: fixture 901513); `maxLevel` is the level of the lowest level id among the teacher's classes; codes listed once, level order then id; classes attended = enrolment not removed (status column not read); `selfTeacher` skips a teacher with no name like GROUP_CONCAT (so it can be shorter than `attendingClass`); sort by lower-case ASCII name then token; a teacher without a member row or a class without a level is not listed.
- **Registrations:** guard is `registrations:read` for the gender (a gender lock from that action), and PHP has NO row scope beyond the gender here (the "open registrations only for all or gender" rule of the recon belongs to the allocated download, not to this list): a coordinator with assigned classes sees every waiting person of their locked gender. One row per token with `MAX()` of every column: the status is the greatest TEXT (Rejected > Pending > Accepted), so one Rejected form hides the member and a Pending+Accepted member shows "Pending" with the highest id and the latest day; members in an active class (enrolment not removed), with an `@thestrongrope.com` email (case-insensitive), or with no account are left out; the requested class shows only while that class is active; `islamicStudyYears` is text, free texts are entity-decoded, empty strings are null. The gender is the stored text compared with "1"/"2" exactly.
- **Student card:** `classes:read` (403) is held by every member, so a plain member gets 404 (not 403) from PHP; token <= 0, unknown, in no class, or in none of the caller's reach is one 404 "Person not found"; reach is `classes:read` (all / gender / assigned ids), never the asked gender; classes in code order, level "" when the class has none.
- **This week:** the window is the last completed week (week of today minus 7 days, `ReportCalendar`) plus eight weeks before; rows come from the weekly classes (reach AND, for an assigned-only `classes:read`, the assigned classes), the subjects taught from the plain reach; `NF` newest = form missing and not counted in `of`; a class's own start (started_on, else creation day) turns earlier weeks into n/a; conduction list by streak desc then class id (PHP array_multisort compares the rows, first key the id); `met` and `attended` rows carry no teacher mobile; the mobile is shown only for a teacher `TeachersModel::canView` allows (decided once per teacher gender: every listed teacher teaches); attendance average and percent round half away from zero (`PhpFloat`).
- **This week class:** reach is asked for the class's OWN gender (like the history route); eight Sunday weeks newest first; subject topic written, else "Conducted"; `chart` = `data/syllabus_topics.json` entry of the level (null for any level but MIQDAD).

### MariaDB to PostgreSQL ports (deliberate)
`GROUP_CONCAT(DISTINCT .. ORDER BY ..)` and the two aligned lists -> C# (`ReportActiveTeachersSlice.Build`, unit tested); `MAX()` of an enum -> `max(status::text collate "C")` (string maximum, not enum position); `MAX()` of text columns -> `collate "C"` (MariaDB's is case-insensitive: only differs for mixed-case ties); `NOT LIKE` -> `not ilike`; `date('Y-m-d')`, `current_date()` -> UTC today passed in (`TimeProvider`); `if(c.started_on is null, created_at, started_on)` -> `coalesce(started_on, (created_at at time zone 'UTC')::date)`; `round()` -> `MidpointRounding.AwayFromZero` through `decimal`; `substr(created_at,0,10)` -> `to_char(.. at time zone 'UTC')`; no integer-versus-decimal division reaches SQL (fractions are `double` in C#, as PHP floats). NUL bytes: none of the five routes sends a text to SQL (gender, ids and tokens are numbers; a token that is not a number reads as 0), so there is no 500 path.
