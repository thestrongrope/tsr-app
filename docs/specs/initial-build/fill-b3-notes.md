Quirks: Monday-to-Sunday week (a Sunday closes the week before), slot count includes deleted slots (at least 1), any session counts. Dates: PHP's `strtotime` is read for Y-m-d (one or two digit parts, overflowing day rolls on, time and offset read at UTC), YYYYMMDD, d-m-Y, m/d/Y, "20 September 2025" and the weekday variants, today/tomorrow/yesterday. - GET .../conduction/new: `features/conduction-new/`, `conduction-new.hurl`. Quirks: last day = newest session of any kind else `started_on` else null; next day counts deleted slots; with no schedule PHP reads an undefined index (7 minus the weekday). The PHP parity stack prints PHP warnings before the JSON for a class with no schedule (display_errors on), so those two cases match the body as text; production presumably hides them (unverified).
- GET .../conduction/{session_id}: `features/conduction-get/`, `conduction-get.hurl`. The session must belong to the class (a session of another class is 404, tested both ways); attendance shows members who left, with their current name.
- POST /classes/{id}/conduction: `features/conduction-create/`, `domain/ConductionWriter.cs`, `conduction-create.hurl` + `-new-api.hurl`; db test `ConductionWritesTests`. Event `classes.session_recorded` {classId, sessionId, recordedBy}; none for a replay, a 409 or a refusal. Quirks: validation counts the body's present students BEFORE the member filter drops strangers (a body whose only present student is a stranger is 201 with attendance 0); the filter keeps any token that ever had a row in the class; absent students get recitation 0; the five flags are stored '0'/'1'; `teacher` = the class's teacher now; created_by = caller; `conducted_by` never set; replay = same class, day, caller and recordedAt (clamped to now, cut to the second, unreadable = absent); future dates and duplicate student tokens accepted. Deviations: one transaction with a class-row lock (PHP: none, a race could double-record); a NUL byte, a text over its column (reason 100, topic 1000, extra name 100) or a number beyond int32 (duration, surah, verse, recitation, extra token) is 422 (checked after PHP's rules, only on what is stored); recordedAt is read as ISO 8601 only (PHP's DateTime reads more).
- PUT .../conduction/{session_id}: `features/conduction-update/`, `conduction-update.hurl` + `-new-api.hurl`. Event `classes.session_updated` {classId, sessionId, updatedBy}. Order: class, permission, session 404, 403 "not editable" (before the body), 422, 409. Keeps teacher, created_by, created_at; sets updated_at, updated_by; attendance deleted and written again. The edit window ignores who the caller is (PHP passes canManage true), so an admin cannot edit an old record either.
