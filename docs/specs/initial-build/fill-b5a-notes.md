### Quirks copied (each is in a Hurl file on both sides)
- **Gender:** the caller's locked gender overrides `?gender=` silently; otherwise only the exact text `2` is ladies, anything else gents. Never a refusal; the 403 is `reports:read` for that gender (`en_ladmin` asking for gents gets ladies, `rp_coord` asking for ladies gets gents).
- **Demo class** `AYD1` and **closed classes** never appear (the history of a closed class is `[]`, not 404).
- **Conduction:** weeks are Sunday to Saturday numbered per calendar year; the window is the months of the week's first and last day made whole weeks and capped at this week; a class that held two sessions in a week has two rows and counts twice (expected 8 for 9581, not 7); `Students` are those of the class's first row; `Registered` is today's roster; a percentage of a thousand or more becomes **0** (PHP `number_format` writes "1,000", `api_cast` reads it as not numeric); `weekOf` is the last row of the week; an unknown week (2025 week 53) reads as the epoch (1970 window, empty lists, previous and next null).
- **Conduction order:** `cast(substr(code, 3) as unsigned)`: for `SM-7` the text is `-7` and MariaDB wraps a negative to 2^64 - 7, so SM-7 sorts before SM-5 and a code with no number after the dash is 0. Ported (a regex prefix plus the wrap). Ties (several classes with key 0) have no order in MariaDB; the new API adds the week start, the day and the id.
- **Conduction CSV:** PHP's raw rows, headers with a space in quotes, `Started On` as `YYYY-MM-DD 00:00:00` (the class's start day, else its creation time), `%age Conduction` a four-decimal quotient (`0.3333`), `0` for no students, empty when the class has no `extra_students` (NULL + n is NULL) or no attendance. Two sessions of one week come in no fixed order on PHP, so the Hurl file asserts each line, not the whole file.
- **Weekly:** the cell logic is ported literally (`Yes (2)` then a day not held turns the cell into `No`); the first week takes the month of its LAST day, the others the month of their first day; a day with two sessions counts once (the later one); scope is `reportClasses`: the `reports:read` reach AND, for a caller whose `classes:read` is assigned-only, the assigned classes (PHP `getAll`); the sessions of a class whose teacher has no member row are dropped (inner join).
- **Summary:** only classes with a schedule slot in a finished week are listed (inner join on the expected slots); expected slots count from 2021-11-01; no 12-month limit; no schedule rows deleted; `subjects` is null unless some subject was taught. **`from` has no default: PHP builds it with `strtotime('first day of this')`, which is false, so a request without `from` is always 422 "from and to must be months..." on PHP.** Copied (one line to change if the intended default, three months back, is wanted). Every figure is a whole number.
- **Subject conduction:** a class asked for that the caller does not reach (or that is closed or missing) is 403 after the months are read; `levels` are those of the rows before the level and class narrowing; label is the calendar year plus `WEEK(d, 1)` (so the New Year weeks carry PHP's wrong year); a subject taught with no topic reads "Conducted"; topics of a week are joined with "; " once each; the date is that of the week's last session.
- **Class sessions list:** the last session is the one with the latest day; the quran text is `surah` and `:verse` only when the verse is not 0 (so "2"); a class with no session has null for the last fields; classes whose level or teacher is missing still appear (left joins).
- **History:** reach is asked for the class's OWN gender; the quran text is `surah:verse` whenever the verse is not null (so `2:0`), unlike the list; newest first (ties: the later id).
- **Class-sessions CSV:** quran cell is `CONCAT(surah, ':' || verse)` (empty without a surah, `:0` for a verse of 0), `Yes`/`No`, reasons starting with `=` get the leading quote; file name `Class_Sessions_Report_<Gents|Ladies>_<Ymd_His>.csv` (the gender of the answer); 404 "No sessions to download".

### MariaDB to PostgreSQL ports (deliberate)
`calendar_table` -> `ReportCalendar` (`WEEK(dt, 0)`; 2010-01-01 to 2040-12-31 as PHP's seed); `WEEK(d, 1)` -> `SubjectWeeks.WeekMode1` (Monday first, week 1 has four days, late December can be 53). **Checked against PHP only for 10 to 24 Nov 2025 (week 46 to 48); the New Year cases (2025-12-29 is 53, 2026-01-01 is 1, 2021-01-01 is 0) rest on the unit tests and MariaDB's documented rule, not on a PHP answer** (an oracle check needs a ladies class with sessions on 2025-12-29 and 2026-01-01 and one subject-conduction request over 12-2025 to 01-2026: not done); `dayofweek(d)` -> `extract(dow) + 1`, compared with `class_schedules.day` as it is; `least(now(), date)` / `greatest` -> day comparisons (UTC today; PHP's file name time equals its `Date` header, so the server runs UTC); decimal division (four decimals, rounded half up) -> `Math.Round(x, 4, AwayFromZero)` before the `* 100` and the final `round()` (`SummaryFigures`); `round()` and `number_format` -> `MidpointRounding.AwayFromZero`; `cast(... as unsigned)` -> the numeric prefix with the 2^64 wrap; NULL ordering: the level order sorts NULL first (`nulls first`) in the two left-joined lists; `CONCAT` returning NULL for a NULL part -> coded by hand (not `concat()`); `IN ('1', 'Y')` is case-insensitive on both (the columns are citext); `LENGTH - LENGTH(REPLACE(x, '\n', ''))` -> `char_length`; `DATE_FORMAT('%d %b %Y')` -> `dd MMM yyyy` in the invariant (English) culture; `date >= datetime` (`From >= Started On`) -> `timestamp` comparison with the creation time as UTC; group by `y, w` with a week split at New Year -> `Weeks`; integer division never reaches SQL (all ratios are done in C# on decimals); a NUL byte: none of the routes sends a text to SQL (months are matched by a regex, `level` and `gender` are compared in memory, ids are numbers), so there is no 500; `level=A%00B` is a 200 with no class (new-API Hurl file).

## Deviations from PHP (D8)
- A week with no calendar day, or a window wholly in the future (week 10 of 2100): PHP answers 200 with warnings and a fatal error in the body (or notices before the JSON); the new API answers an empty report (`report-conduction-new-api.hurl`), the download 404.
- Bounds PHP does not have: 20000 class ids, 50000 week rows, 100000 weekly sessions, 50000 subject sessions, 5000 sessions in a history, 200000 CSV rows (production holds about 24000 sessions and 220 active classes).
- The class-sessions list and CSV break ties between sessions of one day by the id; the conduction rows add the day and the id after the week start. PHP leaves ties unordered.
- Months are read with IntOfText: "05-2025\n" is accepted (as PHP) and read as 05-2025.
- Not copied: topic de-duplication in subject conduction is exact (PHP's `in_array` is loose, so "1" and "1.0" would collide); the level compare is exact and case-sensitive as PHP's `===`.
