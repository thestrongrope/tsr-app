### Quirks copied (each is in a Hurl file on both sides unless marked)
- **Pending:** the class list is PHP `getAll` (`reports:read` reach AND, for an assigned-only `classes:read`, the assigned classes: `KeepAssignedAsync`); a named `reports:read:all` grant does NOT widen it (db test). Forms not filled = expected minus submitted of the summary query (a class with no slot in a finished week has none); the MCQ figures ignore the months entirely: standard MCQs not deleted of the class's level and language (language 1 when the class has none: db test, not Hurl, the two sides seed different MCQs), each row counted once, conducted = a live copy with a publish time, pending = a live copy without one, deactivated copies ignored, a code matches case-insensitively (`b5c-m1`); teachers by forms desc, MCQs pending desc, ASCII lower-case name, stable; the level narrows AFTER `levels` is listed and recounts the totals; a level of only NUL is trimmed to empty (no narrowing). `from` and `to` default to last month and this month (UTC); `to` alone before today's month is 422 on both sides.
- **TSR:** LEVEL rows use the reach without the gender narrowing (a level with no class of the asked gender still shows, total 0) and the `gents_*`/`ladies_*` figures are picked; class lists use the asked gender and inner join the teacher and the gender. Levels are `cl.code` (MK), pending and students use `cl.name`. A level's recitation row exists only where an attendance mark is in the range. The MCQ day is a time: a quiz published after midnight of `to` is outside (Hurl: noon on the 5th shows only for `to=...-06`); `lastConducted` of the MCQ list is `YYYY-MM-DD HH:MM:SS` (UTC), the conduction one a day. Percent is a float (`100.0`, `PhpFloat`); a class's attendance is present over marks at four decimals, a level's the MariaDB average of those at eight decimals, then a whole percent. **The recitation CLASS list has no status condition in PHP: a closed class with recitation appears there** (Hurl on both sides: RC-G-568 for the gents administrator; db test). A class assigned by a rule is an active one in the new API (`ClassScopes`), so a coordinator never sees it there; PHP `class_access` rows could name a closed class (not verifiable, no fixture).
- **Students:** reach is `reachFilter` like TSR (a named grant widens it, db test); only students with an attendance mark of a held session in the range; one row per enrolment not removed (a student in two classes is two rows, each with its class's figures); quizzes by publish time as a time; figures at four decimals, the score their mean at eight; `token` is a string. **The recitation is PHP's global leaderboard:** every mark of the range (held or not, any class) summed per token and ranked over everyone, THEN limited to enrolments with status `A` (not `removed_at`) in an active class, to members whose own gender text is the asked one, and, for an assigned-only caller, to the assigned classes; the first 1000 ROWS by rank count (two enrolments of one token are two rows); a student outside gets 0. Hurl proves: a student with status I but not removed (901924), a ladies-class student whose member gender is gents (901926), marks in a session not held counted (901921: 100000), the same token in two classes (901922); db test proves the assigned-class limit.
- **Date rule (new, `domain/ReportDates.cs`):** `[0-9]{4}-[0-9]{2}-[0-9]{2}` with a trailing newline allowed, `checkdate` (year 0000 is not a date), from after to compared as TEXT, more than 366 days is "The range can cover at most a year"; defaults are today and 14 (tsr) or 30 (students) days before the `to` that was given. A default `from` before year 1 is 422 (PHP builds "0000-..", which fails `checkdate`), never a crash.

### MariaDB to PostgreSQL ports (deliberate)
`RANK() OVER` is the same; ties at the 1000-row cut and ties of equal figures have no order in PHP, so rows are ordered by token, class id or class code (a tie is never asserted in Hurl: the fixtures have exact ties on purpose in two files, asserted by filter); decimal division (`ReportFigures.Quotient`: four decimals, half up, zero divisor 0; the score's `/ 3` at eight) and `(int) round((float) x * 100)` (`WholePercent`) are unit tested; NULL ordering of `ORDER BY ... DESC` (NULL last in MariaDB) is `NewestFirst`/`HighestFirst`; `strnatcmp` is `NaturalCompare` (port of PHP's `strnatcmp_ex`, 13 cases); `datetime` compared with a date (midnight) is a UTC `timestamptz` compare; `avg()` of decimals is the sum of four-decimal quotients over the count at eight decimals; `GROUP BY` order of the unordered recitation class list is by class id. NUL: no text parameter reaches SQL in any of the three routes (days are validated first, the gender is a number, a level is compared in C#), so there is no 500 path; the `-new-api` files prove it.
