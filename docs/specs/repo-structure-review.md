# Review: repo-structure.md (draft, 2026-11-08)

Independent adversarial review of `docs/specs/open-source/repo-structure.md` (uncommitted draft),
against `origin/develop` decided docs and the real code. Line numbers: `RS:` = the plan;
`TA:` = `docs/specs/target-architecture/plan.md`; `OS:` = `docs/specs/open-source/plan.md`;
`SDS:` = `docs/specs/open-source/software-data-split.md`. Settled premises (domain-first, slices,
modular monolith, gateway, Flutter) are not reopened.

## Verified OK

- Dart SDK constraint `^3.8.1` (`mobile/pubspec.yaml:8`) meets the workspace minimum of 3.6.
- The runner applies one ordered directory (`main.go:59` `-dir`, default `migrations`) and keys rows by file name and checksum, so "db/ cannot be split by domain" holds.
- `web/models/` holds 43 files.
- `web/api-docs.json` has 191 paths, and the tag counts quoted (`admin` 51, `classes` 43, `reports` 37, `mcq` 18, `me` 17) are right as operation counts.
- The notifier reads and writes only `notifier_*` tables (`notifier/db.js`), so it does not break rule 2.
- `POST /feedback` as Stage 2's first slice matches TA:146-151.
- The `mobile-api.` alias staying until `minimumBuild` passes matches TA:104-105.
- `codemagic.yaml` must stay at the root, and it uses `working_directory: mobile` (`codemagic.yaml:3-4, 43, 67, 151`). It needs one edit per workflow when the app moves.
- Directory-scoped `.claude/skills` are discovered with a path prefix by Claude Code.
- `AGENTS.md` already exists at the root.
- Moving units 1-11, 14 and 25 matches SDS:296-325. Units 12-13 and 15-29 are out of scope, as stated.
- nginx is already used in TSR repos (tsr-gems, tsr-hadith-corpus).
- The Alpine healthcheck note matches the global rule (BusyBox `wget`, no `curl`).
